# Rev E archive: Fanou, the desk lighthouse

Rev E was a small lighthouse: the lidar turned in the lantern, the screen was a window in the tower and both radars slept behind the painted bands. Rev F (the upright robot, [`hardware/cad/marvin.scad`](../../cad/marvin.scad)) replaced it in September 2026, because measuring heart rate at the desk needs the 60 GHz radar aimed at a seated chest.

The files here are kept for reference and are not maintained:

| Path | What |
|---|---|
| `cad/fanou.scad` | Parametric OpenSCAD source |
| `stl/` | Print-ready parts (base island, bottom plate, tower shell, spine, gallery cap, lidar template) |
| `blender/` | Assembly and print layout, with the script that builds them |
| `images/` | Renders |
